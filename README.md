# Tomorrow’s Reserve

Carbon savings without borrowing tomorrow’s water.

[Open the public demo](https://tomorrows-reserve.vercel.app/) · [Source repository](https://github.com/andreajanewilliams/tomorrows-reserve)

The public demo checks the whole day in your browser and replays clearly labelled local contract runs. Run the project locally to execute new contract checks.

Tomorrow’s Reserve checks pumping plans against whole-day water and carbon accounting, and refuses a saving claim that leaves tomorrow short of water.

The project is in [`pumpproof/`](pumpproof/) (its original codename). Start with its [README](pumpproof/README.md) for setup and the demo, then see the [submission documents](pumpproof/docs/submission/).

```sh
cd pumpproof
npm ci
npm start
```
