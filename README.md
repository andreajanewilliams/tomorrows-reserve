# PumpProof

PumpProof checks pumping plans against whole-day water and carbon accounting, and refuses a saving claim that leaves tomorrow short of water.

The project is in [`pumpproof/`](pumpproof/). Start with its [README](pumpproof/README.md) for setup and the demo, then see the [submission documents](pumpproof/docs/submission/).

```sh
cd pumpproof
npm ci
npm start
```
